  <p>
    Costuma-se dizer no Aikido que o <em>Ukemi Waza</em> (técnica de
    rolamento) é nossa primeira defesa, já que através da execução de um
    correto Ukemi mantemos nossa integridade física quando da aplicação
    de um Nage Waza (técnica de projeção).
  </p>
  <ul class="technique-list">
    <li>
      <span class="technique-name">Mae Kaiten Ukemi</span>
      <span class="technique-description">Rolamento completo para frente.</span>
    </li>
    <li>
      <span class="technique-name">Ushiro Kaiten Ukemi</span>
      <span class="technique-description">Rolamento completo para trás.</span>
    </li>
    <li>
      <span class="technique-name">Ushiro Hanten Ukemi</span>
      <span class="technique-description">Meio rolamento para trás.</span>
    </li>
    <li>
      <span class="technique-name">Tobi Ukemi</span>
      <span class="technique-description">Queda feita rolando no ar e apenas com a terminação no solo.</span>
    </li>
  </ul>
</div>

<div class="techniques-section">
  <h2 class="technique-category-title">Osae Waza — Técnicas de Imobilização</h2>
  <p>
    As técnicas de imobilização constituem um dos seis princípios conhecidos
    por Pilares Básicos do Aikido.
  </p>
  <ul class="technique-list">
    <li>
      <span class="technique-name">1º Princípio — Daí Ikkyo (Ude Osae)</span>
      <span class="technique-description">Controle do braço.</span>
    </li>
    <li>
      <span class="technique-name">2º Princípio — Daí Nikyo (Kote Mawashi)</span>
      <span class="technique-description">Torção interior do braço.</span>
    </li>
    <li>
      <span class="technique-name">3º Princípio — Daí Sankyo (Kote Hineri)</span>
      <span class="technique-description">Torção com alongamento do pulso.</span>
    </li>
    <li>
      <span class="technique-name">4º Princípio — Daí Yonkyo (Tekubi Osae)</span>
      <span class="technique-description">Controle com pressão do pulso.</span>
    </li>
    <li>
      <span class="technique-name">5º Princípio — Daí Gokyo (Ude Nobashi)</span>
      <span class="technique-description">Estiramento completo do braço.</span>
    </li>
  </ul>
</div>

    <strong>Jo</strong> (bastão). O estudo segue os ditames técnicos

  </p>
